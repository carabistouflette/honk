# Recursive discovery local samples

Both reports measure clean commit `21fd79d`, five rounds for each of2/16/64/256
identities including parent sentinels. Every raw sample is retained. The native
scanner, membership verifier and1000 explicit-root checks are timed independently;
kernel watch installation, Goose dispatch and child command time are excluded.
Short shallow local trees are not a deep-tree or multi-root qualification.

no competitor, throughput ranking or latency-percentile claim. Sources, compiler
and measured binary remain stable across each run.
