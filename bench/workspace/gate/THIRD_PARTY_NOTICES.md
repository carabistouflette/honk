# Third-party source

`version_rules` uses [goose-semver](https://github.com/carabistouflette/goose-semver)
at `2311ae69a7edacb545f284b02e345be07dd2fb05` under Apache-2.0. Honk fetches the
source from that exact Git revision. Its license is included in the upstream
source tree. This package includes the local `version_rules` library and its
Apache-2.0 license under `vendor/rules/`.
